# ⚡ TecnoCalidad — Tienda E-Commerce MVP (Shopify Style)

Tienda e-commerce moderna desarrollada con **HTML5, React 18, Tailwind CSS, Python REST API y SQLite**.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend**: HTML5, React 18, Tailwind CSS, Canvas Confetti.
- **Backend**: Python 3 (HTTPServer nativo, sqlite3, hashlib, secrets).
- **Base de Datos**: SQLite3 relacional con tablas `products`, `orders`, `order_items`, `audit_log`.

---

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/bastixori/tienda.git
   cd tienda
   ```

2. **Configurar el entorno**:
   Copia el archivo de ejemplo para crear tu entorno local:
   ```bash
   cp .env.example .env
   ```

3. **Iniciar el servidor**:
   ```bash
   python server.py
   ```

4. **Abrir en el navegador**:
   Visita `http://localhost:3000`
